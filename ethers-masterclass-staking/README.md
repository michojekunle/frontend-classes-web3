## 🚀 Quick-Start Guide for Class

```bash
# 1. Navigate to frontend
cd frontend

# 2. Install dependencies
npm install

# 3. Start dev server
npm run dev
```

Open `http://localhost:5173` and follow along with the instructor to implement `frontend/src/hooks/useWeb3Staking.ts`!
